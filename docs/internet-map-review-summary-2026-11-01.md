# 2026-11-01 설계 검토 반영 요약

ChatGPT·Gemini·Claude·Perplexity·DeepSeek·Grok에서 새 검토 답변을 확인했다. 다섯 곳은 계획서 7장 원문과 목적/구조 요약을, DeepSeek은 평가계획 고정 요약을 검토했다. 전체 스키마 동일 조건 감사나 실제 성능 실험이 아니다. 일부 제공자의 정확한 모델 버전은 관측하지 못했다.

## 채택한 결정

- R0는 신규 발견, R1은 등록 후 활용을 평가한다. 점수 차이를 지도 개선 효과로 해석하지 않는다. 개발·등록 항목 회수·미사용 자원 계열 일반화 과제를 구분한다.
- 전체 인터넷 recall을 주장하지 않는다. 고정 reference-set 회수율·필수 정보 coverage·공식 확인 정밀도·차단 해소를 구분한다.
- 소규모 파일럿과 확증 시험을 분리한다. 90%·시간10%·토큰15%·비열등성 기준은 후속 검증 가설로 유지한다.
- 지도 우선·웹 검색·원 디렉터리 우선 조건의 시작점·허용 도구·오염·예산을 고정한다. 초기 스키마 학습 비용을 포함하고 구축·유지 비용은 별도 보고한다.
- 토큰·정확한 모델 버전 미관측은 null/not_observed로 기록한다. 바이트·문자·호출을 실토큰으로 환산해 성능을 주장하지 않는다.
- 서울 POI–OD를 발견/연결 가능성 판단/읽기 전용 표본 결합으로 구분한다. 공식 ID 근거가 없을 때 올바른 보류는 실제 결합 성공이 아니다.

## 채택하지 않은 제안

웹 검색 대조군 삭제, R0/R1 통합, 서울 과제·실제 연결 검증 삭제, 보류를 실제 작업 성공으로 세는 제안은 사용자 목적에 맞지 않아 제외했다. 모든 R0 발견 항목을 R1 정본에서 빼자는 제안도 등록 후 활용 평가와 충돌해 제외했다. AI의 추가 기술 사실은 공식 원천 확인 전 확정하지 않는다.

## 구현과 확인 범위

이번 변경은 공통 분류 DAG, 정보원 스키마·근거/참조 검사·검색/상세 생성, 후보 종류 필터 및 같은 분류 내 검색을 구현한다. 현재 정보원 정본은 0건으로 R0 시작 상태를 유지한다. 기존 표본은 7 Service·16 Operation이며 서울 데이터 수집/등록은 후속 작업이다.

자동 검사는 분류 순환·없는 부모 거부, 재현 빌드, 상위 분류 소속, 근거 없는 active 정보원 거부, 정보원/기능 인덱스 분리, Binding 간 제약 혼합 방지, 미검증 근거의 unknown 판정, 기존 17개 질의 smoke를 포함한다. 이 결과는 사람 화면 사용성, 지도 효용, R0 18~36회 비교 실험의 완료를 뜻하지 않는다.

개인 웹 대화 주소와 원문 수집 기록은 공개 저장소에 포함하지 않는다.
