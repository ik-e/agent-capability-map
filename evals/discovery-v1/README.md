# 판단 재사용 개발 시험 계약

이 폴더는 후속 평가 하네스의 요청·결과 계약과 개발용 세 과제를 담는다. 공개 카탈로그 스키마와 과거 R0 결과 계약은 변경하지 않는다. 세 과제는 독립 holdout이 아니며, 아직 모델 비교 시행을 수행하지 않았다.

## 판정

`task.schema.json`은 검증 수준·필수조건·선호조건·예산·종료 조건을, `result.schema.json`은 후보별 조건 판정·근거·단계 상태·종료 참조를 정의한다. `scripts/discovery_contracts.py`는 추가 의미 규칙을 검사한다.

- 해당 검증 수준에 적용되는 필수조건을 종료 목록에서 삭제할 수 없다.
- 조건 판정은 선택한 동일 후보/Binding의 관측 근거에 연결되어야 한다. 검색 요약은 공식 문서 본문 관측으로 취급하지 않는다.
- `evaluated_requirement_ids`와 `unchecked_requirement_ids`를 분리한다. 검색 필터의 `satisfies`로 나머지 조건을 충족했다고 간주하지 않는다.
- 근거 URL·관측 시각은 실제 응답 이벤트와 맞아야 한다. 허용 유형·버전·최대 경과일 조건에 어긋난 근거로 확정 판정을 내릴 수 없다.
- 요청의 `as_of`는 과제 기준시점이다. 근거의 경과시간은 컨트롤러가 기록한 실제 판정 시각을 기준으로 계산한다. 자기보고 시각으로 최초 적합 후보 시간을 만들지 않는다.
- 근거 내용이 실제 주장을 뒷받침하는지, 출처가 정말 공식인지에 대한 판단은 별도 원문 채점이 필요하다. 계약 검증 통과만으로 사실 정확성을 보증하지 않는다.

## 직접 계측하는 연구 도구

`scripts/research_mcp.py`는 **시험 전용** stdio MCP다. 운영자 지정 HTTPS 호스트에서 query/open/find/click을 계측한다. 브라우저 제어 도구나 공개 호스팅 서비스가 아니다.

```powershell
py -3.12 scripts/research_mcp.py --log evals/runs/example/events.jsonl --budget 12 --seconds 300 --hosts open-meteo.com geocoding-api.open-meteo.com
```

같은 로그가 존재하면 시작을 거부한다. `research.batch`에 들어온 각 하위 동작의 원문 인자·고유 ID·시작/종료·상태·반환량·응답 SHA256을 기록하고 응답 자료를 같은 비공개 실행 폴더에 저장한다. 실패·timeout·재전송도 각각 계수하며 남은 예산을 넘는 batch는 실행 전에 전체 거부한다. 시간 만료로 batch가 중단되면 미실행 수를 명시한다. 내부 HTTP 리다이렉트는 별도 네트워크 시도로 기록하고 논리 동작 수와 섞지 않는다.

query는 `TAVILY_API_KEY` 환경변수가 준비된 경우 Tavily를 사용한다. 키는 JSON 인자·로그에 넣지 않는다. 키가 없으면 검색이 준비되지 않은 상태로 표시하며 다른 비공식 검색 서비스로 우회하지 않는다. open/click은 명시적 허용 호스트·공개 주소·HTTPS·기본 포트만 허용하고 리다이렉트마다 재확인한다. 이는 개발용 제한이며 DNS 재바인딩 등을 포함한 운영용 네트워크 격리를 검증한 구현은 아니다.

## 실행과 상태

```powershell
py -3.12 scripts/test_discovery_preflight.py
py -3.12 scripts/verify_discovery_live.py
py -3.12 scripts/prepare_discovery_comparison.py
```

첫 명령은 정상·미확인·충돌·만료·접근 차단·무결과·예산·잘못된 완료·첫 후보/첫 적합 판정 구분 등을 검사한다. 모의 backend 결과는 실제 인터넷 조사나 모델 성능으로 채점하지 않는다. CI에는 네트워크 없는 계약·계측 검사만 포함한다.

두 번째 명령은 실제 stdio MCP와 공식 문서·읽기 전용 좌표 응답을 점검하고 `evals/runs/discovery-live-*/summary.json`에 상태를 남긴다. 검색이 준비되지 않으면 문서·API 조회가 성공했더라도 전체 비교 gate는 `blocked`다. 현재 활성 도구의 검색 연결도 별도 점검에서 503을 반환했다. 성공 가능한 열람을 검색 성공으로 대체하지 않는다.

세 번째 명령은 2개 Operation과 관련 Binding·Evidence 26개 레코드의 개발 입력을 동결한다. 두 조건은 사실과 URL 집합이 같고, 추가 안내는 이미 있는 관계 ID의 순서만 제공한다. 추가 입력 바이트도 모델 입력 비용에 포함해야 한다. 입력 준비는 실제 모델 비교나 효과 입증이 아니다. 실제 시험 전에는 검색 연결·과제 버전·시작/종료 기록·모델·순서·독립 문맥·예산을 새 프로토콜로 잠근다.

원문 이벤트·응답·개별 입력 패킷은 Git 제외 경로에 보관하고, 공개 결과는 검토한 집계만 내보낸다. 검색 gate 통과 후 소규모 비교와 서울 정보원 등록·회수 검증을 이어가며 과거 R0 점수를 소급 수정하지 않는다.
